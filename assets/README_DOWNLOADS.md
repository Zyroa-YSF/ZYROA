# Assets download instructions and placeholders

This folder will contain models and sounds downloaded from Sketchfab, Poly Pizza, and Freesound.

Planned folders:
- assets/models/
- assets/sounds/
- assets/music/

Download workflow (to follow):
1) Search Sketchfab with keywords like "elevator door lowpoly", "realistic apartment props", "bench street". Filter by "Downloadable" and license (CC0/CC-BY/CC-BY-NC).
2) Use Poly Pizza to locate quick models with permissive licenses.
3) For sounds use Freesound queries: "footsteps concrete", "tunnel ambience", "elevator hum", "door creak". Filter by license and prefer CC0/CC-BY.

Do NOT add models requiring purchase or restricted redistribution.

When assets are downloaded, add lines to assets/ATTRIBUTIONS.md with exact filename, author, URL and license.
