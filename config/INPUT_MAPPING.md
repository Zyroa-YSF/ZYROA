# Input mapping and controls

Default control actions used in scripts:
- ui_left / ui_right / ui_up / ui_down — movement (keyboard arrows / WASD)
- ui_accept — jump (Space)
- interact — interact / use / E key
- attack — primary attack (Left mouse button)
- flashlight_toggle — toggle flashlight (F)

Mobile controls:
- Touch virtual joystick for movement
- On-screen buttons for jump, interact, attack, flashlight

Add these inputs in Project > Input Map in the Godot editor before running on device, or update project.godot with custom mapping.
